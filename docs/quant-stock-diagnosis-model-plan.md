# A股量化诊股模型方案

## 1. 模型目标

本模型限定在 A 股市场，使用 Tushare 可获取的数据构建日线级别的量化诊股模型。模型每日更新，用于评估个股当前状态，并预测未来约一个月，即未来 20 个交易日的涨跌概率。

核心输出包括：

- 未来 20 个交易日上涨概率
- 未来 20 个交易日跑赢大盘概率
- 当前估值水平
- 个股综合评分
- 可解释诊断结论

建议同时预测两个目标：

```text
绝对收益标签 = 未来20个交易日复权收益率 > 0
超额收益标签 = 未来20个交易日个股收益率 - 同期基准指数收益率 > 0
```

其中，绝对收益用于判断股票未来是否上涨，超额收益用于判断股票是否具备相对市场的配置价值。

## 2. 数据范围

数据来源限定为 Tushare 可获取的数据，不局限于当前数据库中已有的数据。

建议使用以下数据类型：

| 数据类别 | Tushare 数据 | 主要用途 |
| --- | --- | --- |
| 股票基础信息 | stock_basic、namechange | 股票池、上市日期、ST 状态过滤 |
| 日线行情 | daily、pro_bar、adj_factor | 收益率、波动率、趋势、复权价格 |
| 每日指标 | daily_basic | PE、PB、PS、市值、换手率、量比 |
| 技术因子 | stk_factor | MACD、KDJ、RSI、BOLL 等技术指标 |
| 财务指标 | fina_indicator | ROE、ROA、毛利率、净利率、成长性 |
| 财务报表 | income、balancesheet、cashflow | 利润、资产负债、现金流质量 |
| 资金流向 | moneyflow | 主力资金、大单、小单流入流出 |
| 融资融券 | margin、margin_detail | 杠杆资金偏好 |
| 股本与解禁 | share_float | 限售股解禁压力 |
| 股权质押 | pledge_stat、pledge_detail | 股权质押风险 |
| 龙虎榜 | top_list、top_inst | 短期活跃资金与机构行为 |
| 大宗交易 | block_trade | 大宗交易折溢价和成交规模 |
| 分红回购 | dividend、repurchase | 股东回报与管理层信号 |
| 行业分类 | index_member、ths_member 或申万行业相关接口 | 行业中性化与行业内估值比较 |

## 3. 股票池与样本处理

建议股票池规则：

- 仅保留 A 股普通股票
- 剔除 ST、*ST、退市整理股票
- 剔除上市不足 120 个交易日的新股
- 剔除长期停牌或流动性极差股票
- 剔除未来 20 个交易日无法形成完整标签的样本

样本构造方式：

```text
样本 = 某股票在某交易日的全部特征
标签 = 该股票未来20个交易日后的收益方向
```

需要特别注意避免未来函数：

- 财务数据只能在公告日之后使用
- 业绩预告、业绩快报只能在披露日之后使用
- 复权价格用于收益率计算，但不能引入未来复权信息
- 行业分类应使用当时有效的分类信息

## 4. 特征体系

模型特征分为六大类，既用于建模，也用于最终解释。

### 4.1 行情与动量因子

数据来源：

- daily
- pro_bar
- adj_factor
- stk_factor

建议特征：

- 近 5、10、20、60 日收益率
- 近 20 日相对行业超额收益
- 近 20 日相对基准指数超额收益
- 收盘价相对 MA20、MA60、MA120 的位置
- 20 日、60 日波动率
- 20 日、60 日最大回撤
- 成交额放大倍数
- 换手率变化
- RSI、MACD、KDJ、BOLL 等技术指标

解释示例：

```text
该股近20日表现强于行业，且成交额温和放大，说明短期趋势和资金关注度均有改善。
```

### 4.2 估值因子

数据来源：

- daily_basic
- fina_indicator
- income
- balancesheet

建议特征：

- PE、PE_TTM
- PB
- PS、PS_TTM
- 股息率
- 总市值、流通市值
- PE 历史分位
- PB 历史分位
- 行业内 PE 分位
- 行业内 PB 分位
- PEG
- PB-ROE 匹配度

估值判断不应只看 PE 或 PB 的绝对高低，而应结合行业、盈利能力和成长性。

解释示例：

```text
该股当前PB处于自身近五年较低分位，同时ROE高于行业中位数，说明估值与盈利能力相比并不昂贵。
```

### 4.3 质量因子

数据来源：

- fina_indicator
- income
- balancesheet
- cashflow

建议特征：

- ROE
- ROA
- 毛利率
- 净利率
- 经营现金流 / 净利润
- 资产负债率
- 有息负债率
- 应收账款周转率
- 存货周转率
- 商誉 / 净资产
- 扣非净利润占比

解释示例：

```text
公司盈利能力较强，ROE和净利率均高于行业多数公司，且经营现金流能够覆盖净利润，利润质量较好。
```

### 4.4 成长因子

数据来源：

- fina_indicator
- income
- 业绩预告
- 业绩快报

建议特征：

- 营收同比增长率
- 净利润同比增长率
- 扣非净利润同比增长率
- 单季度营收增速
- 单季度净利润增速
- 最近 3 年营收 CAGR
- 最近 3 年净利润 CAGR
- 毛利率同比变化
- 业绩预告净利润增速

解释示例：

```text
公司最近两个季度收入和利润增速改善，基本面边际变化转好。
```

### 4.5 资金与交易行为因子

数据来源：

- moneyflow
- margin
- margin_detail
- top_list
- top_inst
- block_trade

建议特征：

- 主力净流入 / 成交额
- 大单净流入 / 成交额
- 小单净流入 / 成交额
- 融资余额变化率
- 融资买入额 / 成交额
- 龙虎榜机构净买入
- 大宗交易折溢价率

解释示例：

```text
近20日主力净流入改善，融资余额同步增加，说明中短期资金偏好改善。
```

### 4.6 风险与事件因子

数据来源：

- stock_basic
- namechange
- suspend_d
- share_float
- pledge_stat
- pledge_detail
- repurchase

建议特征：

- 是否 ST 或存在退市风险
- 近期停牌频率
- 近期涨跌停次数
- 股权质押比例
- 未来 30 日解禁市值 / 流通市值
- 商誉 / 净资产
- 资产负债率异常程度
- 回购金额 / 市值

解释示例：

```text
未来一个月存在较大规模限售股解禁，且股权质押比例偏高，因此风险评分被下调。
```

## 5. 特征处理

建议处理流程：

1. 按交易日构建横截面样本
2. 对异常值进行缩尾处理，例如 1% 和 99% 分位截断
3. 对特征做行业中性化和市值中性化
4. 对特征做横截面标准化
5. 对缺失值使用行业中位数或专门缺失标记处理
6. 对财务类低频数据进行向前填充，但必须遵守公告日约束

处理后的特征既可用于模型训练，也可转换为可解释评分。

## 6. 算法方案

建议采用“两层模型”。

### 6.1 第一层：可解释因子评分

将特征归入六个维度：

- 动量评分
- 估值评分
- 质量评分
- 成长评分
- 资金评分
- 风险评分

每个维度形成 0 到 100 的子评分，再合成为综合评分。

该层的作用是增强解释性，让用户能够理解股票为什么好或为什么差。

### 6.2 第二层：概率预测模型

建议模型优先级：

1. Elastic Net Logistic Regression
2. Explainable Boosting Machine 或 GAM
3. LightGBM + SHAP + 概率校准

#### Elastic Net Logistic Regression

优点：

- 解释性强
- 稳定
- 适合作为基准模型

缺点：

- 对非线性和特征交互刻画较弱

#### Explainable Boosting Machine / GAM

优点：

- 解释性较好
- 可刻画非线性
- 适合输出单因子贡献

缺点：

- 工程复杂度高于线性模型

#### LightGBM + SHAP

优点：

- 预测能力通常较强
- 能处理非线性和高维特征
- 可通过 SHAP 做单股解释

缺点：

- 本身属于黑盒模型
- 需要额外做解释约束和概率校准

推荐生产组合：

```text
基准模型：Elastic Net Logistic Regression
主模型：LightGBM 或 EBM
解释层：六大因子评分 + SHAP/GAM贡献
概率校准：Isotonic Regression 或 Platt Scaling
```

## 7. 估值模型

估值水平建议单独建模，不完全依赖涨跌预测模型。

估值输出包括：

- 自身历史估值分位
- 行业内估值分位
- 质量调整后的估值偏离

建议方法：

### 7.1 历史分位

计算个股 PE、PB、PS 在过去 3 年或 5 年中的分位数。

示例：

```text
PE历史分位 = 当前PE在过去5年PE序列中的位置
PB历史分位 = 当前PB在过去5年PB序列中的位置
```

### 7.2 行业分位

在同一交易日，将个股估值与同行业公司比较。

示例：

```text
行业PB分位 = 当前PB在同行业股票中的分位
行业PE分位 = 当前PE在同行业股票中的分位
```

### 7.3 质量调整估值

使用行业内回归模型估计合理估值：

```text
合理PB = f(ROE, 净利润增速, 毛利率, 资产负债率, 市值)
估值偏离 = 当前PB - 合理PB
```

可使用 Ridge、Huber Regression 或 LightGBM 回归。为了保持解释性，优先使用分行业线性或稳健回归。

不同行业适用的估值指标应有所差异：

| 行业类型 | 优先估值指标 |
| --- | --- |
| 银行、保险 | PB、PB-ROE |
| 周期行业 | PB、EV/EBITDA、盈利周期位置 |
| 消费行业 | PE、PE_TTM、股息率 |
| 科技成长 | PS、PEG、营收增速 |
| 公用事业 | 股息率、PE、现金流稳定性 |

## 8. 训练与验证

不能使用随机切分，应采用时间序列切分。

示例：

```text
训练集：2014-2021
验证集：2022-2023
测试集：2024-2025
滚动实盘验证：2026 以后
```

建议验证方式：

- 时间序列滚动训练
- 横截面分组回测
- 按预测概率分为 5 组或 10 组
- 检查高分组是否持续跑赢低分组
- 检查不同市场环境下的稳定性

核心评估指标：

- AUC
- Log Loss
- Brier Score
- 分组收益
- 多空收益
- 信息系数 IC
- Rank IC
- 最大回撤
- 换手率
- 胜率

## 9. 输出解释格式

单股诊断建议输出：

```text
股票：示例股份
未来20日上涨概率：62%
未来20日跑赢大盘概率：57%
综合评分：74/100
估值水平：合理偏低

主要正面因素：
1. 质量较好：ROE高于行业中位数，经营现金流覆盖净利润。
2. 估值不贵：PB处于自身历史较低分位，行业内估值也不高。
3. 趋势改善：近20日相对行业出现超额收益。

主要负面因素：
1. 短期资金流入不明显，成交额尚未显著放大。
2. 未来一个月存在一定解禁压力。

结论：
该股当前估值合理偏低，基本面质量较好，未来一个月上涨概率高于市场平均水平，但短期资金推动力一般。
```

## 10. 推荐落地路径

建议分阶段实现。

### 第一阶段：可解释基线版

- 完成 Tushare 数据拉取
- 建立日线样本表
- 构建六大类核心因子
- 建立估值分位模型
- 建立 Logistic Regression 基准模型
- 输出单股诊断报告

### 第二阶段：增强预测版

- 引入更多资金与事件因子
- 使用 LightGBM 或 EBM
- 加入概率校准
- 加入 SHAP 或 GAM 单股解释
- 做滚动回测

### 第三阶段：生产化

- 每日自动更新数据
- 每日生成全市场股票评分
- 缓存模型预测结果
- 建立模型监控
- 记录因子漂移和预测稳定性

## 11. 最终推荐

推荐采用如下整体方案：

```text
数据：Tushare 日线行情 + 每日指标 + 财务指标 + 资金流向 + 融资融券 + 风险事件
预测目标：未来20交易日绝对上涨概率 + 超额上涨概率
主算法：EBM 或 LightGBM + 概率校准
解释框架：六大因子评分 + SHAP/GAM贡献
估值模型：历史分位 + 行业分位 + 质量调整估值
验证方式：时间序列滚动训练 + 横截面分组回测
```

如果优先追求解释性，建议使用：

```text
因子评分 + Elastic Net Logistic Regression + GAM/EBM
```

如果优先追求预测效果，建议使用：

```text
因子评分 + LightGBM + SHAP + 概率校准
```

实际项目中建议先实现解释性强的基线版本，再逐步引入更复杂的非线性模型。

## 价格使用规则
收益率/动量/标签：使用后复权价或基于 adj_factor 构造的点时复权价
估值/市值/换手/成交额：使用 daily_basic / daily 原始字段
回测成交：使用未复权 OHLC
用户展示价格：使用未复权 close
